# KOMA · Anime clips for editors

A concept project by **Prema**: a clip library for anime editors that works like editing software.

**Live site:** https://iputusathyapremasuarbawa-stack.github.io/koma/

## What's inside

- A cinematic intro with its own soundtrack (plays on the first visit only)
- Hover previews and a frame-by-frame clip player with timecodes
- A cut room: a small timeline editor with trimming, transitions and EDL export
- A case study page at `#case`
- Glowing cursor effects, light and dark themes, and reduced-motion support

Everything is one HTML file. All thumbnails, previews and intro shots are drawn in code on a canvas, and the soundtrack is generated in the browser with the Web Audio API. There are no image, video or music files, apart from the share preview image.

## Custom intro music (optional)

Put an audio file named `intro-music.mp3` next to `index.html` and the intro will play it instead of the built-in soundtrack. Only use music you have the rights to.
